# 🗂️ Folder Organizer Script

> Tidy a messy folder in one command: files are sorted into folders by extension.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

## Features

- 🔍 File-type detection by extension
- 📁 Creates category folders automatically
- 🛡️ Safe file moving
- ♻️ Duplicate handling so nothing gets overwritten

## Run

```bash
git clone https://github.com/ishitarawatt/folder-organizer.git
cd folder-organizer
python "folder organizer.py"
```

> Tip: try it on a copy of a folder first.

## Tech stack

Python · `os` · `shutil` (standard library only, nothing to install)
